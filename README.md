# دانلودر یوتیوب (Flask + yt-dlp)

نسخه آماده برای استقرار روی **Render** با حفظ منطق اصلی دانلود شما.

## ویژگی‌ها

- تحلیل لینک‌ها قبل از دانلود
- پشتیبانی از کیفیت‌های `240p` / `360p` / `best` (همان منطق اصلی)
- نمایش پیشرفت زنده (درصد، سرعت، ETA، لاگ)
- **دانلود مستقیم فایل به سیستم کاربر** (نه فقط ذخیره روی سرور)
- پاک‌سازی خودکار فایل‌های قدیمی قبل از جاب جدید (مهم برای دیسک موقت Render)

## ساختار پروژه

```
yt-downloader/
├── app.py              # بک‌اند اصلی
├── templates/
│   └── index.html      # رابط کاربری فارسی
├── requirements.txt
├── Dockerfile          # برای نصب ffmpeg روی Render
├── .gitignore
└── README.md
```

## استقرار روی Render (توصیه: Docker)

1. این پوشه را به یک مخزن GitHub پوش کنید.
2. در [Render Dashboard](https://dashboard.render.com) → **New** → **Web Service**
3. مخزن را انتخاب کنید.
4. تنظیمات:
   - **Runtime**: Docker
   - **Instance Type**: Free (یا Starter اگر نیاز به پایداری بیشتر دارید)
5. Deploy را بزنید.

Render به صورت خودکار از `Dockerfile` استفاده می‌کند و `ffmpeg` را نصب می‌کند.

### اگر بدون Docker خواستید (Native)

- Build Command:
  ```bash
  pip install -r requirements.txt
  ```
- Start Command:
  ```bash
  gunicorn --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 300 app:app
  ```
- توجه: در حالت Native باید خودتان `ffmpeg` را به محیط اضافه کنید (معمولاً سخت‌تر است و توصیه نمی‌شود).

## نکات مهم برای Render

| موضوع | توضیح |
|-------|--------|
| دیسک موقت | فایل‌ها بعد از ری‌استارت سرویس پاک می‌شوند. بعد از دانلود حتماً فایل را به سیستم خودتان ذخیره کنید. |
| محدودیت رایگان | سرویس رایگان بعد از مدتی بی‌استفاده sleep می‌شود و ممکن است کند باشد. |
| بلاک شدن یوتیوب | IPهای دیتاسنتر گاهی توسط یوتیوب بلاک می‌شوند. اگر خطای «Sign in to confirm you're not a bot» دیدید، از کوکی مرورگر یا پروکسی استفاده کنید. |
| حافظه | دانلود ویدیوهای با کیفیت بالا ممکن است حافظه زیادی مصرف کند. ترجیحاً از `360p` استفاده کنید. |

## استفاده محلی

```bash
# ساخت محیط مجازی
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate

pip install -r requirements.txt

# اگر ffmpeg نصب نیست:
# Ubuntu/Debian: sudo apt install ffmpeg
# macOS: brew install ffmpeg
# Windows: از سایت ffmpeg.org دانلود کنید و به PATH اضافه کنید

python app.py
```

سپس به `http://127.0.0.1:5000` بروید.

## منطق کیفیت (همان نسخه اصلی)

| کیفیت | فرمت yt-dlp | توضیح |
|-------|-------------|--------|
| 240   | `133+140`   | نیاز به ffmpeg برای ادغام ویدیو+صدا |
| 360   | `18`        | تک‌فایله، همیشه صدا دارد |
| best  | `bestvideo+bestaudio` | بهترین کیفیت موجود |

## امنیت

- این ابزار برای استفاده شخصی طراحی شده.
- وضعیت پیشرفت به صورت سراسری (global) نگه داشته می‌شود → در صورت استفاده همزمان چند نفر ممکن است تداخل ایجاد شود.
- فقط فایل‌های داخل پوشه `downloads` قابل دانلود هستند.
